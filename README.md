# ใบสมัครอบรมช่างโซลาร์เซลล์

หน้าเว็บแบบฟอร์มสมัครอบรม (`index.html`) ที่ส่งข้อมูลผู้สมัครเข้า Google Sheet ผ่าน Google Apps Script (`apps-script.gs`)
ผู้สมัครไม่ต้องล็อกอิน ใช้ได้ทั้งมือถือและคอมพิวเตอร์

## 1. สร้าง Google Sheet และติดตั้งสคริปต์ (ประมาณ 5 นาที)

1. ไปที่ https://sheets.new สร้างชีตใหม่ ตั้งชื่อ เช่น "ผู้สมัครอบรมโซลาร์"
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมใน `Code.gs` ทั้งหมด แล้ววางเนื้อหาจากไฟล์ `apps-script.gs`
   - ถ้าต้องการอีเมลแจ้งเตือนเมื่อมีคนสมัคร ใส่อีเมลที่ `NOTIFY_EMAIL`
4. กดบันทึก (ไอคอนแผ่นดิสก์)
5. กด **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ประเภท: **เว็บแอป (Web app)**
   - เรียกใช้ในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
6. กด Deploy แล้วอนุญาตสิทธิ์ (ถ้าขึ้นหน้า "Google hasn't verified this app" ให้กด Advanced → Go to ... (unsafe) เพราะเป็นสคริปต์ของคุณเอง)
7. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

## 2. เชื่อมหน้าเว็บกับชีต

เปิด `index.html` หาบรรทัดนี้ แล้ววาง URL ที่คัดลอกมา

```js
const CONFIG = {
  SCRIPT_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec'
};
```

ถ้ายังไม่ใส่ URL หน้าเว็บจะทำงานใน **โหมดทดลอง** (มีกรอบสีเหลืองแจ้งไว้ และไม่บันทึกข้อมูล)

ทดสอบ: เปิด `index.html` ในเบราว์เซอร์ กรอกแล้วกดส่ง จะได้เลขที่ใบสมัคร เช่น `SOL-2611-0001` และมีแถวใหม่ในแท็บ "ผู้สมัคร"

## 2.1 (ทางเลือก) ให้ Apps Script แสดงหน้าฟอร์มเอง ไม่ต้องใช้ GitHub

1. ในหน้า Apps Script กด **+** ข้างคำว่า "ไฟล์" → **HTML** → ตั้งชื่อ `index` (ระบบเติม `.html` ให้เอง)
2. ลบโค้ดเดิมในไฟล์นั้น แล้ววางเนื้อหาทั้งหมดจาก `index.html`
3. ตรวจว่า `Code.gs` เป็นเวอร์ชันล่าสุดจาก `apps-script.gs` (มี `HtmlService` ใน `doGet`)
4. **Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: New version → Deploy**
5. เปิด URL `/exec` เดิม จะเห็นหน้าฟอร์มทันที นำลิงก์นี้ไปแชร์ได้เลย
   - เช็กระบบได้ที่ `.../exec?ping=1`
   - บัญชี Gmail ทั่วไปจะมีแถบเทาด้านบนว่า "This application was created by a Google Apps Script user" เป็นเรื่องปกติ

## 3. เผยแพร่ให้คนทั่วไปเข้าถึง

ทางเลือกที่ง่ายที่สุดคือ GitHub Pages: สร้าง repo ใหม่ อัปโหลด `index.html` แล้วเปิด Settings → Pages → Deploy from branch (`main` / root)
จะได้ลิงก์ เช่น `https://<ชื่อบัญชี>.github.io/<ชื่อ-repo>/` นำไปแชร์ใน Facebook / LINE หรือทำ QR Code ได้

## การจัดการผู้สมัครในชีต

- คอลัมน์สุดท้าย **สถานะ** เป็นดรอปดาวน์: รอติดต่อ / ติดต่อแล้ว / ยืนยันเข้าอบรม / ยกเลิก
- เบอร์โทรเก็บเป็นข้อความ เลข 0 ด้านหน้าไม่หาย
- ระบบมีช่องดักบอท และตรวจข้อมูลจำเป็นซ้ำที่ฝั่งสคริปต์

## แก้ไขเนื้อหา

- **รูปหัวเว็บ** คือไฟล์ `hero.jpg` เปลี่ยนเป็นรูปของคุณเองได้โดยวางไฟล์ชื่อเดิมทับ (แนะนำแนวนอน กว้างประมาณ 1280–1920px)
  รูปปัจจุบัน: "Solar panels in the desert" โดย U.S. National Park Service, สาธารณสมบัติ (Public domain) จาก Wikimedia Commons
- **หัวข้อหลักสูตร** อยู่ในส่วน `<!-- 3 -->` ของ `index.html` (การ์ด `opt-card`)
- **เพิ่มช่องใหม่**: เพิ่ม input ใน `index.html` แล้วเพิ่มคู่ `['ชื่อช่อง', 'หัวคอลัมน์']` ใน `FIELDS` ของสคริปต์
  ถ้าแก้ `FIELDS` หลังจากมีข้อมูลแล้ว ให้เพิ่มหัวคอลัมน์ในชีตเองให้ตรงลำดับ
- หลังแก้สคริปต์ทุกครั้ง ต้อง **Deploy → Manage deployments → แก้ไข (ไอคอนดินสอ) → Version: New version** URL จะยังเหมือนเดิม
